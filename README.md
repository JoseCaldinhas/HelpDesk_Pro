# 🎫 HelpDesk Pro

Sistema de gerenciamento de chamados de suporte de TI desenvolvido para praticar conceitos de desenvolvimento web e CRUD.

## 🚀 Funcionalidades

* Criar chamados
* Visualizar chamados
* Editar chamados
* Excluir chamados
* Alterar status
* Filtrar chamados
* Pesquisar chamados
* Definir categoria e prioridade
* Dashboard com métricas
* Armazenamento dos dados no navegador
* Interface responsiva

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 📂 Estrutura

```text
HelpDesk-Pro/
├── index.html
├── style.css
└── script.js
```

## ▶️ Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## 📚 O que pratiquei

Neste projeto pratiquei JavaScript, manipulação do DOM, eventos, CRUD, filtros, armazenamento de dados
